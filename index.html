Desarrollo Web

El desarrollo web permite crear sitios y aplicaciones que pueden ser utilizados desde diferentes dispositivos. HTML proporciona la estructura de una página mientras que CSS permite modificar su apariencia y presentación.

HTML

¿Qué es HTML?

HTML es el lenguaje utilizado para estructurar el contenido de una página web. Mediante diferentes elementos se pueden organizar títulos, párrafos, imágenes, enlaces y otras partes del contenido.

CSS

Selectores

Los selectores permiten identificar los elementos de HTML a los cuales se les aplicarán diferentes estilos.

Propiedades

Las propiedades CSS permiten modificar características como colores, tamaños, márgenes, bordes y espacios.

Diseño responsivo

El diseño responsivo permite que una página pueda adaptarse a diferentes tamaños de pantalla.
