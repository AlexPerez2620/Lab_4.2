Laboratorio 4.2: Elaboración de una página web estilizada mediante CSS

Este proyecto consiste en el desarrollo de un sitio web con HTML5 y CSS.

La página emplea una estructura semántica a través de componentes como son: header, nav, main, section, article y footer.

Se emplearon diversos tipos de selectores CSS, como los de identificadores, clases y elementos.

Se emplearon además varias propiedades de CSS para alterar elementos visuales como los colores, las dimensiones, los márgenes, los espacios y los bordes.

El modelo de caja CSS se aplica en el proyecto a través del uso de border, margin y padding.

Por último, para posibilitar que la página se ajuste a distintos tamaños de pantalla, se utilizó un diseño responsivo mediante media queries.
